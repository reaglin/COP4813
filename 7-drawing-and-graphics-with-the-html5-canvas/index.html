Students explore the HTML5 Canvas API to programmatically draw shapes, paths, text, and images using JavaScript, laying the foundation for interactive graphics in the browser.

    A reading that explains the Canvas path system — including beginPath(), moveTo(), lineTo(), stroke(), arc(), and curves — showing learners how to define and render complex shapes and line-based drawings step by step.
