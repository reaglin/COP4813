COP4813 — Module 7

Drawing and Graphics with the HTML5 Canvas

This module introduces the HTML5 Canvas API and teaches you how to programmatically draw shapes, paths, text, and images directly in the browser. You will explore colors, gradients, and styles, then progress to image manipulation and interactive, event-driven graphics — building the practical skills needed for data visualizations, games, and rich web applications.
