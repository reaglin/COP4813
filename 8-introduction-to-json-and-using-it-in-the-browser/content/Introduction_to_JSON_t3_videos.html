Introduction

JSON (JavaScript Object Notation) is a text format for representing structured data. When data arrives from a web API, a configuration file, or browser storage, it arrives as a string — not as a usable JavaScript object. Parsing is the step that bridges that gap: JSON.parse() reads a JSON-formatted string and returns the corresponding JavaScript value, whether that is an object, an array, a number, a string, a boolean, or null.

Because parsing depends entirely on the input being well-formed, this topic also covers what counts as valid JSON: double-quoted keys and strings, no trailing commas, no comments, no functions or undefined values, and correct nesting of objects and arrays. When the string is malformed, JSON.parse() throws a SyntaxError, so wrapping the call in try...catch is the standard defensive pattern. You will also meet the optional second argument to JSON.parse(), the reviver function, which lets you transform values as they are read — for example, converting an ISO date string into a real Date object.

As you watch, pay attention to three things: the distinction between a JSON string and a live JavaScript object, exactly which characters make a string invalid, and how parsed arrays can then be looped over with ordinary JavaScript. These habits carry directly into the fetch-and-render work later in this module.
