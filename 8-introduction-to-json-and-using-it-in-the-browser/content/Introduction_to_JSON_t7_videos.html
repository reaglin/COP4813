Introduction

Fetching JSON is only half the job. Once the data arrives, it exists only as values in memory — nothing appears on screen until you write code that turns those values into HTML the browser can display. This topic covers that final step: selecting a container element on the page to act as a render target, parsing the fetched response into a JavaScript object or array, and then generating markup from it.

There are two common ways to produce that markup. You can build an HTML string (often with template literals) and assign it to an element's innerHTML, or you can create nodes programmatically with methods such as document.createElement, set their text and attributes, and append them to the page. Both work; each has trade-offs in readability, performance, and safety when the data comes from an untrusted source. Because JSON data is usually an array of records, you will almost always combine one of these techniques with a loop so that one row, card, or list item is generated per item.

As you watch, pay attention to three things: where in the code the author grabs the target element, how the parsed data is looped over, and how the generated markup actually gets attached to the document. Also notice what happens when the data changes — whether the code clears and rebuilds the container or appends to what is already there. Those patterns are exactly what you will reuse in your own assignment code.
