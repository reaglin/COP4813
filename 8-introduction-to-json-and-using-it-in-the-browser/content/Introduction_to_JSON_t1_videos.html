Introduction

JSON, short for JavaScript Object Notation, is a lightweight text format for representing structured data. It grew out of JavaScript's object literal syntax, but it is now a language-independent standard that servers, browsers, mobile apps, and APIs all use to exchange information. When a web page asks a server for data, the response you receive is very often a JSON string.

In this course, JSON is the bridge between the server and the browser. Before you can fetch data with the Fetch API or XMLHttpRequest and render it on a page, you need to be comfortable reading JSON, recognizing valid syntax, and understanding exactly how a JSON string differs from a live JavaScript object in memory. That distinction is what makes JSON.parse() and JSON.stringify() necessary rather than optional.

As you watch the videos below, pay attention to the small syntax rules that trip people up: double quotes around every key, commas between members but never after the last one, and the limited set of allowed value types (string, number, boolean, null, object, array). Also watch for how objects and arrays nest inside one another, since real API responses are usually several levels deep.
