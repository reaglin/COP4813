Introduction

A website becomes a website — rather than a pile of separate files — when its pages are connected. Internal navigation is the system of links that lets a visitor move from the home page to an about page, a gallery, or a contact form and back again without ever typing a URL. The core tool is the anchor element, and the skill that makes it work is writing correct relative file paths: addresses that describe where a file sits in relation to the page currently being viewed.

In this topic you will practice writing links such as about.html, pages/contact.html, and ../index.html, and you will see why a path that works on one page may break on another once files are moved into folders. You will also build a navigation menu — a group of links, usually inside a nav element, repeated in the same place and same order on every page so users always know where they are and what their options are. Finally, you will use fragment identifiers (the # syntax paired with an element id) to jump directly to a section within a long page.

As you watch the videos below, pay attention to three things: how the href value changes depending on where the file lives, how the folder structure of the site is organized before any links are written, and how a navigation block is copied and kept consistent across pages. Keep a small test site open and try each path yourself — broken links are usually a typo or a wrong folder level, and the fastest way to learn the rules is to break and fix them.
