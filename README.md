# COP4813

This course covers development of web systems with a focus on client-side development. Topics include use of XHTML, the Document Object Model (DOM), Cascading Style Sheets (CSS), use of Javascript for providing client side interactivity, ADA accessibility, Javascript Object Notation (JSON), and design for mobile platforms. A web site design project is included.

## Modules

1. 1 -GitHub, GitHub Pages, and Your First HTML Page
2. 2 -Building a Full Website with HTML, Images, and Links
3. 3 -Styling Web Pages with CSS
4. 4 - Introduction to the Document Object Model (DOM)
5. 5 - Creating and Validating HTML Forms
6. 6 - External Libraries: jQuery, Bootstrap, and Plotting Tools
7. 7 - Drawing and Graphics with the HTML5 Canvas
8. 8 - Introduction to JSON and Using It in the Browser
9. 9 - Implementing Drag and Drop Interactions
10. 10 - Animation Techniques in the Browser
11. 11 - Designing Mobile-Ready and Responsive Websites
12. 12 - Dynamic Objects and Controls with JavaScript and the DOM
13. 13 - Building a Browser-Embedded Game
14. 14 - Content Management Systems, Webmaster Roles, and Site Maintenance
