COP4813 — Module 2

Building a Full Website with HTML, Images, and Links

This module guides learners through the process of constructing complete, multi-page websites using HTML. Topics span site architecture, semantic markup, embedding images with accessible attributes, and building both internal and external hyperlinks — culminating in a hands-on walkthrough of planning and publishing a coherent site from scratch.
