Module 3 Styling Web Pages with CSS

This module introduces Cascading Style Sheets (CSS) as the language that controls the visual presentation of web pages. You will explore CSS syntax, selectors, the box model, typography, color, and modern layout techniques — including Flexbox and Grid — building the skills needed to craft polished, well-structured web interfaces.

Introduction to CSS
Topic Detail .html

This reading introduces CSS as a stylesheet language, explains how it separates visual presentation from HTML structure, and covers how to apply styles using inline, internal, and external methods, serving as a learner's first conceptual foundation for the module.

CSS Selectors
Topic Detail .html

This reading explains CSS selectors — including type, class, ID, attribute, and pseudo-class selectors — and how specificity determines which rules win when multiple rules conflict, helping learners precisely target HTML elements for styling.

The Box Model
Topic Detail .html

This reading covers the CSS Box Model, explaining how every HTML element is rendered as a rectangular box composed of content, padding, border, and margin, so learners can accurately control spacing, sizing, and layout behaviour.

Typography and Colors
Topic Detail .html

This reading covers CSS typography properties (font family, size, weight, line height, spacing) and color tools (named colors, hex, RGB, HSL, and background colors), enabling learners to style text and establish a visual hierarchy on web pages.

CSS Layout Techniques
Topic Detail .html

This reading covers CSS layout techniques including normal flow, the display property, Flexbox, and CSS Grid, teaching learners how to arrange and align page elements beyond the browser's default document flow.
