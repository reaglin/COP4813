Introduction

CSS selectors are the part of a style rule that answers the question "which elements should this styling apply to?" Every rule you write begins with a selector, so learning the selector vocabulary — element (type) selectors, class selectors, ID selectors, and the various ways of combining them — is the foundation for everything else you will do with CSS in this module.

Once you can target elements precisely, a second question arises: what happens when two or more rules try to style the same element in different ways? That is where specificity and the cascade come in. Specificity is a scoring system that ranks selectors (ID selectors outrank class selectors, which outrank element selectors), and the cascade adds rules about source order, origin, and importance. Understanding both lets you debug "why isn't my style applying?" instead of guessing.

As you watch the videos below, pay attention to three things: the exact syntax for each selector type (the dot for classes, the hash for IDs, spaces and commas between selectors mean very different things), when it is appropriate to use a class versus an ID, and how specificity is calculated when rules conflict. Try typing the examples into your own stylesheet and changing them — selector behavior is much easier to remember once you have broken a rule and fixed it yourself.
