Introduction

Up to this point you have mostly worked with HTML that already exists in the page. In this topic you learn to build markup at runtime: JavaScript's document.createElement() produces a new element node that lives in memory, and you then configure it — setting textContent or innerHTML, adding attributes with setAttribute(), assigning classes or an id — before it ever appears on screen. Only when you insert the node into the document with a method such as appendChild(), insertBefore(), append(), prepend(), or insertAdjacentElement() does the browser render it.

This matters because almost every dynamic interface you will build in this course — a list that grows as users add items, a table filled from fetched data, a modal or alert generated on demand — depends on creating and placing elements precisely. Choosing the right insertion method controls where the new content lands relative to a reference element: inside at the end, inside at the start, immediately before, or immediately after. The same techniques let you assemble nested structures (for example, building an li, appending a span and a button to it, and then appending the whole li to a ul) so that a single insertion adds a complete component.

As you watch, pay attention to three things: the exact position each method produces relative to the reference element, the difference between methods that take element nodes and those that accept strings of HTML or plain text, and the fact that you must first select a target element before you can insert anything into it. Try to re-type each example yourself in a scratch page or online editor rather than only watching — insertion order is much easier to remember once you have seen it move content around on your own screen.
