Introduction

So far in this module you have learned to find elements that already exist on the page and change their text, attributes, styles, and classes. This topic goes a step further: instead of only editing what the browser built from your HTML, you will build new nodes in JavaScript and attach them to the document yourself. That is how interactive pages add a new to-do item, render a list of search results, show a notification banner, or delete a row when a user clicks a button.

The workflow is usually the same three steps. First, create a node in memory with document.createElement() (or clone an existing one with cloneNode()). Second, give it content and configuration by setting textContent, innerHTML, or attributes such as id, class, and src. Third, attach it to the tree with appendChild(), append(), insertBefore(), or insertAdjacentElement(), depending on exactly where it must land. Removal and swapping follow the same logic in reverse, using removeChild(), the simpler element.remove(), and replaceChild() or replaceWith().

While watching the videos, pay attention to two things. First, notice that a created element does nothing visible until it is inserted into the document — forgetting that insertion step is the most common beginner bug. Second, watch the difference between the older parent-based methods (parent.appendChild(child), parent.removeChild(child), parent.replaceChild(new, old)) and the newer child-based ones (append(), remove(), replaceWith()), and note which ones accept text strings and multiple arguments. Also keep an eye on when innerHTML is a convenient shortcut and when it is risky compared with building nodes explicitly.
