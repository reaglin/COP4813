Introduction

Before you can change anything on a page with JavaScript, you have to be able to find the thing you want to change. DOM selection is the process of asking the browser's document object for a reference to one or more elements in the page's node tree. Once you hold that reference in a variable, it becomes your handle for reading content, changing styles, attaching events, or removing the element entirely.

In this topic you will work with the core vanilla JavaScript selection methods: getElementById for a single element with a unique id, querySelector for the first element matching any CSS selector, and querySelectorAll for a static list of all matching elements. You will also practice scoped selection, which means calling querySelector or querySelectorAll on an element reference instead of on document so the search is limited to that element's descendants. This is how you avoid accidentally grabbing the wrong card, row, or button on a page with repeated markup.

As you watch, pay attention to three things. First, the return value of each method: a single element, null when nothing matches, or a NodeList that may be empty. Second, the CSS selector syntax being passed in, since querySelector accepts the same selectors you already write in stylesheets. Third, how the presenter checks the result in the console before using it, because reading and verifying your selection is what prevents the null-reference errors that break scripts further down the file.
