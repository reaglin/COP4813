COP4813 — Module 6

External Libraries: jQuery, Bootstrap, and Plotting Tools

This module introduces the use of popular third-party JavaScript and CSS libraries in web development. Learners will explore how to load external libraries via CDN, harness jQuery for DOM manipulation and event handling, build responsive layouts and polished interfaces with Bootstrap, and create interactive data visualizations with Chart.js — culminating in a project that combines all three tools.
