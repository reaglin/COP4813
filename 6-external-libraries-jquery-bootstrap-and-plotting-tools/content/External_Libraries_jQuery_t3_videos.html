Introduction

A web page becomes an application the moment it responds to what the user does. jQuery's event system is the bridge between user actions — clicking a button, submitting a form, typing in a text field, dragging an element — and the DOM manipulation code you already know how to write. In this topic you will focus on .on(), jQuery's general-purpose method for binding handlers, along with the shorthand forms such as .click(), .submit(), and .keyup() that many tutorials still use.

Two ideas deserve special attention. The first is the event object that jQuery passes into every handler: it carries information about what happened (which element, which key, where the pointer was) and gives you methods such as preventDefault() and stopPropagation() to control default browser behavior and bubbling. The second is event delegation — binding a handler to a stable parent element and letting it catch events from children that may not exist yet. Delegation is what makes interactivity work on rows, list items, or cards you generate dynamically after page load.

As you watch the videos below, pay attention to three things: which event is being bound and with what syntax, what selector the handler uses to find the element it changes, and whether the code updates a single element or loops over many. Those same three questions will guide you when you write your own handlers for assignments in this course.
