Introduction

Chart.js is a free, open-source JavaScript library that renders charts onto an HTML canvas element. Instead of hand-drawing graphics or generating images on the server, you include the library (most simply through a CDN script tag), place a canvas in your page, and then write a JavaScript configuration object that tells Chart.js the chart type, the labels and datasets, and any display options. The same basic pattern produces bar, line, and pie charts — only the type value and the shape of the data change.

This topic matters in COP4813 because the data your applications collect is far more useful when users can see it. Chart.js pairs naturally with the other libraries in this module: Bootstrap can make a chart container responsive, jQuery or plain JavaScript can fetch data and update a chart in response to user events, and all three libraries must be loaded in a sensible order for the page to work.

As you watch the videos below, pay attention to four recurring pieces: the script tag that loads Chart.js, the canvas element and its id, the call that creates a new Chart object bound to that canvas, and the structure of the data and options objects. Notice also where the chart's numbers come from — hard-coded arrays, a JSON file, or a server-side query — because the configuration code stays largely the same no matter the source.
