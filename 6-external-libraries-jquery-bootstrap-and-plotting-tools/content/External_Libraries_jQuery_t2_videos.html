Introduction

jQuery is a JavaScript library built to make common browser tasks shorter and more consistent: finding elements on a page, changing their content or attributes, responding to user events, and adjusting styles or visibility. Although modern JavaScript now includes many of the features that originally made jQuery popular, you will still encounter it constantly in existing codebases, in tutorials, and as a dependency of other libraries — including older versions of Bootstrap. Knowing jQuery syntax means you can read and maintain that code as well as write it quickly yourself.

In this course, jQuery is your entry point into working with external libraries. You will practice loading it from a CDN with a script tag, placing that tag in the right position relative to your own scripts, and then using the $ function to select elements with CSS-style selectors. From there, the same patterns carry over to Bootstrap and Chart.js later in the module: include the library, learn its core API, then use it to drive page behavior.

As you watch the videos below, pay attention to three things. First, where the script tags go and what happens if the order is wrong. Second, the shape of a jQuery statement — selector, then method, then arguments — and how methods chain together. Third, the get-versus-set pattern: calling a method with no argument reads a value, while calling it with an argument writes one. Try typing the examples into a small HTML file yourself rather than only watching.

How These Videos Support the Learning Outcomes

Together these three videos build the jQuery foundation the module depends on.
