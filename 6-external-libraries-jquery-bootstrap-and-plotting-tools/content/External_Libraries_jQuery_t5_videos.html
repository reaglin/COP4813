Introduction

Bootstrap is a CSS framework that ships with pre-built, tested UI components — navigation bars, buttons, modal dialogs, cards — plus a large library of small utility classes for spacing, color, text alignment, display, and flexbox behavior. Instead of writing custom CSS for every element, you add class names to your HTML and Bootstrap supplies consistent, responsive styling. This is why Bootstrap remains one of the fastest ways to make a web application look professional without a dedicated designer.

In this course, Bootstrap sits alongside jQuery and Chart.js as the presentation layer of your projects. A navbar gives your pages structure and navigation; cards organize repeated content such as records returned from a server; modals let you collect input or confirm an action without leaving the page; and utility classes let you fine-tune spacing and alignment so that components do not run together. Because Bootstrap's grid and components are mobile-first, the same markup adapts from a phone to a desktop display.

As you watch the videos below, pay attention to the naming patterns rather than memorizing individual classes. Bootstrap class names follow a predictable structure — a property abbreviation, an optional side or breakpoint, and a size or color value — so once you understand the pattern you can read and write most utility classes from memory. Also notice which components depend on Bootstrap's JavaScript bundle (modals and collapsible navbars do) versus those that are purely CSS (buttons and cards), since that affects how you load the library via CDN.
