Introduction

Bootstrap's grid system is the part of the framework you will use most often. It gives you a predictable way to divide a page into rows and columns so that content rearranges itself as the browser window — or the device — gets narrower or wider. The grid is built on a 12-column model: inside a row, you assign each column a number of the 12 available units, and Bootstrap handles the widths, the spacing, and the wrapping for you.

Two ideas make the grid work. The first is mobile-first design: classes without a breakpoint apply at every size, and breakpoint classes such as col-sm, col-md, col-lg, and col-xl only take effect from that screen width upward. The second is structure: a container wraps your layout, rows live inside containers, and columns live inside rows. Getting that nesting right is what prevents the strange gutters and overflow problems beginners run into.

As you watch these videos, pay attention to three things. Watch how the presenter resizes the browser to demonstrate a breakpoint taking effect — that is the fastest way to build intuition about tiers. Note the difference between a fixed-width container and container-fluid. And notice how column classes stack: giving one element both col-12 and col-md-6 means full width on phones and half width from medium screens up. Also look for offset and order utilities, and for examples where a row is placed inside a column to create nested grids.
